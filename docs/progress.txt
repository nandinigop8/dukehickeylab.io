[2026-09-18] Design decisions: Obsidian-style territories, Stromal first
-----------------------------------------------------------------------
- Checked the Stromal data: ~670 genes / 2,000 edges per group; Fertile
  union ~983 genes / 5,303 edges; Fertile vs RIF LH+7 = 1,425 retained,
  575 gained, 575 lost; consecutive steps retain 836-1,123 of 2,000 edges.
  Top LH+7 regulators by out-degree: ZEB1 123, TCF12 87, WT1 77, EBF1 77,
  KLF12 64, TCF7L2 55.
- Decided (user):
    Territories = network modules inside Stromal (not cell compartments,
      since there are no real edges between compartments); hub TF at each
      territory centre; highways = real edges between modules.
    Fertile vs RIF = one merged graph, edges colored retained/gained/lost,
      with a Fertile / RIF / Both toggle.
    LH+3 -> LH+11 = scrubber over one fixed layout from the union graph.
    Look = Obsidian-like, dark.
- Recorded in aesthetic_design.txt section 7 and functionality.txt section 7.

(1)+(2) Literature layer -- script/build_gene_annotations.py (stdlib only):
  - Sources (all public, cached in local_host_development/.cache/, 96 MB,
    do NOT share this folder -- it is re-downloadable):
      NCBI RefSeq gene summaries (MyGene.info), NCBI GeneRIF statements,
      NCBI Gene->PubMed links filtered by an implantation/decidua query,
      CollecTRI TF->target literature (OmniPath).
  - 2,265 genes (all 5 compartments). Stromal tiers: strong (>=10 papers) 22,
    moderate (3-9) 54, limited (1-2) 153, none 771. Top: HOXA10 105, PAEP 78,
    FOXO1 58, STAT3 41, PGR 32, HOXA11 26 -- matches known receptivity biology.
  - GeneRIF classifier: first version let through non-reproductive hits
    ("aortic valve implantation", "flow diverter implantation", "deciduous
    teeth", "endometrial stromal sarcoma"); tightened (implantation/receptivity
    only with a reproductive-context word, "deciduous" excluded, "implantation
    failure" always counts); regression-tested.
  - Paper-count audit: 221/228 recent paper titles behind moderate/strong
    genes are reproductive; the 7 others are PubMed-MeSH-indexed to
    implantation/decidua (one clear miss: KLF12 colorectal cancer paper).
    Tiers are labelled as automated counts, not manual review.
  - curation/implantation_gene_notes.csv: 36 draft notes (hubs, paper-figure
    genes, drivers, classic decidualization TFs) with 86 citations; the build
    fails unless every cited PMID is linked to that gene in NCBI. HPSE2 left
    without a note (its only GeneRIF concerns HPSE, a different gene).
  - CollecTRI: 647 network edges (all compartments) literature-supported;
    one reference-less CollecTRI row (SP1>MT2A) excluded. Stromal: 145 of
    the 2,575 Fertile/RIF LH+7 edges.
  - UI: gene panel "About" (name, evidence tier, draft note + PubMed links,
    or GeneRIF statements, or "Novel candidate"); NCBI function, recent
    papers, other-endometrium findings collapsible; "lit +/-" badges on
    edges; Node colour "Evidence"; "Literature support: All | Genes | Edges"
    filter (replaces "Paper's curated genes only"); right panel lists
    "Known implantation regulators" and "Novel candidates" (hubs/drivers
    with <3 implantation papers).

(3) Territory placement -- build_territory_graph.py:
  - Affinity a_ij = w_ij / sqrt(S_i S_j) (size-independent); target distance
    = touching distance + spread*(1 - a/amax)^1.5; SMACOF stress
    majorisation; push-only overlap removal.
  - Spearman(affinity, edge-to-edge gap): old layout -0.42 -> new -0.78
    (centre distance -0.36 -> -0.70). TERRITORY_SPREAD=6 chosen by sweep
    (8 gives -0.80 but ~40% more empty area).

(4) Validation -- script/validate_site.py (44 checks) +

[2026-09-22] ASTRAEA: name, logo, entry page, device presets, shared toolchain
-------------------------------------------------------------------------------
NAME. The site is ASTRAEA (Greek star maiden) = Atlas of Single-cell
Transcriptional Regulators And Elements of Attachment -- chosen after
checking name collisions: STAR/STARsolo, STARmap, ASTER, ASTERIA (a
commercial scRNA-seq kit), MAIA, KAIROS, DEMETER, PERSEUS, ANDROMEDA,
CASSIOPEIA and ATHENA are all taken in genomics; ASTRAEA, ALCYONE, ASTERISM,
STARLIT and SIDEREAL were free.

LOGO. Rebuilt as vector from the lab's concept (assets/astraea-logo.svg,
astraea-mark.svg): four-point star in a thin broken circle + Cinzel wordmark,
rose-gold gradient #f6ddd3 -> #c17f70. Brand ink #d0988e measures 7.7:1 on
the #111114 canvas, so it stays rose-gold rather than white. The supplied
raster was dropped: its white background baked in, and un-premultiplying it
left the artwork dim on dark.

ENTRY PAGE (index.html, minimal by request: logo + three tabs, 4 words).
The atlas moved to atlas.html. Each tab opens the atlas with a preset:
  desktop  350/350 px panels, both open
  tablet   300/320 px panels, both open
  phone    same widths, both panels closed
?ui= is applied once and then stripped from the URL (history.replaceState),
so a reload or bookmark keeps whatever the visitor chose afterwards; a plain
atlas.html link still works for sharing.

PANEL TOGGLES. "Controls" and "Details" buttons in the atlas top bar collapse
either side panel; the choice is remembered per browser. A hidden panel and
its resizer leave the grid, so the column list is redefined per state --
setting the column width to 0 instead made the map collapse to 0 px (caught
by the new browser check).

SHARED TOOLCHAIN. script/_paths.py resolves site/exports/cache/curation/docs
for either layout: this workspace, or a website repo where the site sits at
the repo root (exports in analysis_data/). Checks that need files kept out of
git now report SKIP with the fix, instead of crashing:
  - no analysis_data/  -> source-comparison checks skipped (32/32 + 3 SKIP)
  - no .cache/         -> CollecTRI re-derivation + citation tracing skipped
